# โต๊ะชิปดีลเลอร์

ดีลเลอร์เปิดห้อง ผู้เล่นเข้ามาลงชิปเองจากมือถือด้วยรหัสห้อง 4 ตัว ไม่ต้องสมัครสมาชิก

- ใช้ Node.js 18 ขึ้นไป ไม่ต้อง `npm install`
- มี 2 ไฟล์หลัก: `server.js` (เซิร์ฟเวอร์) และ `public/index.html` (หน้าเว็บ)

## ลองรันในเครื่อง

```bash
node server.js
```

เปิด `http://localhost:3000` บนคอม ถ้าจะให้มือถือในวง Wi-Fi เดียวกันเข้า ให้ใช้ IP ของคอมแทน เช่น `http://192.168.1.20:3000`

## ขึ้นโฮสต์ฟรีด้วย Render

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub เป็น repo ใหม่
2. เข้า render.com แล้วเลือก **New → Web Service** จากนั้นเลือก repo นั้น
3. ตั้งค่า:
   - Runtime: **Node**
   - Build Command: เว้นว่าง หรือใส่ `echo ok`
   - Start Command: `node server.js`
4. กด Deploy แล้วจะได้ลิงก์ประมาณ `https://ชื่อของคุณ.onrender.com`

แพ็กเกจฟรีของ Render จะหลับเมื่อไม่มีคนใช้ราว 15 นาที เปิดครั้งแรกอาจรอประมาณครึ่งนาที และห้องจะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต ถ้าอยากให้ห้องอยู่ถาวร ใช้แพ็กเกจที่มี disk หรือรันบน VPS

## ขึ้น VPS ของตัวเอง

```bash
node server.js            # พอร์ต 3000
PORT=8080 node server.js  # เปลี่ยนพอร์ต
```

ให้รันค้างไว้ด้วย `pm2 start server.js` หรือ systemd ถ้าวาง Nginx ไว้ข้างหน้า ต้องปิด buffering ของเส้นทาง `/api/stream` (`proxy_buffering off;`) ไม่งั้นชิปจะไม่อัปเดตแบบสด

ห้องเก็บไว้ในไฟล์ `rooms.json` ข้าง `server.js` เปลี่ยนที่เก็บได้ด้วยตัวแปร `DATA_FILE` ห้องที่ไม่มีใครใช้เกิน 24 ชั่วโมงจะถูกลบเอง

## วิธีเล่น

1. **ดีลเลอร์:** เปิดเว็บแล้วกด **เปิดห้อง** จะได้รหัสห้องกับลิงก์สำหรับส่งให้ผู้เล่น
2. **ผู้เล่น:** เปิดลิงก์หรือใส่รหัสห้อง ใส่ชื่อ แล้วจะขึ้นบนโต๊ะพร้อมชิปเริ่มต้น
3. **ผู้เล่น:** ลงชิป ตาม All-in หรือหมอบได้จากมือถือตัวเอง ทุกคนเห็นยอดพร้อมกัน
4. **ดีลเลอร์:** กด **จ่าย Pot** แล้วเลือกผู้ชนะ ถ้ามีคน All-in ยอดไม่เท่ากัน ระบบจะแยก Side pot ให้เอง
5. **ดีลเลอร์:** ลงชิปแทนผู้เล่นคนไหนก็ได้ ย้อนกลับได้ ปรับหรือเติมชิปได้ และเพิ่มผู้เล่นที่ไม่มีมือถือได้ในตั้งค่า

ดีลเลอร์ปิดเบราว์เซอร์ได้ ห้องยังอยู่บนเซิร์ฟเวอร์ เปิดเว็บใหม่บนเครื่องเดิมแล้วกด **กลับเข้าห้อง**
